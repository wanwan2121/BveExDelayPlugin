# BveDelayEx（ランダム遅延・事故プラグイン）

BVE5/6 の **BveEX 拡張機能**です。ランダムな駅で事故・遅延を発生させます。

## 前提
- BveEX 2.1 が導入済みであること（BVE5.8 以降 / BVE6）
- ビルドは GitHub Actions（`.github/workflows/build.yml`）で行えます

## インストール
ビルドで得られた次のファイルを、**BveEX の拡張機能フォルダ**に入れます。
置き場所は BveEX のインストールガイドで確認してください（他の拡張機能の DLL が入っている場所と同じです）。

- `BveDelayEx.dll`
- `crack.png`（人身事故のときのパネルの窓割れ画像。差し替え可）
- `sounds/`（任意。下記の放送ファイル）

## 使い方
BVE の画面で右クリックします。
- 「遅延・事故の発生を有効にする」… チェックで有効／無効
- 「遅延・事故の設定ウィンドウを表示」… 次を設定できます
  - 個数指定（1回の走行で N 駅）／確率指定（各駅で x%）
  - 発生させる事故の種類
  - 停車時間の倍率（動作確認のときは小さく）
  - 今回の発生予定の表示（動作確認用）

設定は DLL と同じフォルダの `BveDelayEx.ini` に自動保存されます。

## 放送（任意）
`sounds/` に wav を置くと、停車したときに鳴ります。
- `announce_0.wav` 人身事故 / `announce_1.wav` 沿線火災 / `announce_2.wav` 車両故障
- `announce_3.wav` 非常ボタン動作 / `announce_4.wav` 踏切支障 / `announce_5.wav` 駅火災
- `announce_6.wav` 車両火災 / `announce_7.wav` 他列車の脱線事故 / `announce_8.wav` 動物支障
- `resume.wav` 運転再開

## パネル表示（任意）
発生中の事故に応じて、ATSパネル配列の `200 + 事故番号`（0〜8）が 1 になります。
車両のパネルでその番号を使えば、ランプなどに使えます。
